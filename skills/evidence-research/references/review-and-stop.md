# Review, continuation and stopping

Use for extended or interrupted research, inconclusive findings and consequential
final conclusions. Review should answer whether further work can change the
decision, not maximize the volume of collected material.

## Check the answer against the question

Review significant requirements from the original brief and later corrections,
not just headings in the draft. Check decisive claims, table cells and derived
conclusions against their actual support. Does an omitted qualification change
the recommendation? Does a validator check truth, behavior or only shape/counts?
Keep unchecked claims visible; do not turn an inaccessible check into a pass.

A separate verification pass can focus attention but is still self-review when
performed by the same executor. If an authorized independent review exists, give
it the original question and evidence boundary, not only your list of findings.
Do not spawn agents or create a new review gate from this procedure.

## Bound further work

Continue for a named unanswered question or conflict that can materially change
the result. Choose the next source or query for its expected information value.
Do not require a minimum number of sources, words, rounds or invented coverage
scores. One authoritative source can answer a narrow contract question.

Repeated sources alone do not establish saturation. Check whether queries and
source families were diverse enough for the task. If access or a real budget
prevents resolution, state the unresolved decision, examined scope and resulting
limit. Never infer that evidence does not exist from a thin first search.

Reuse still-valid source material. Revisit only changed assumptions or affected
branches after new user feedback. For failures distinguish a transient error,
unsupported operation, access refusal and absent result. Use bounded retries or
a suitable lawful alternate representation; repeated identical failure does not
justify retry loops or a silent source substitution.

## Preserve a usable continuation

For substantial interrupted work, keep the question, source locations/versions,
claims checked, material gaps and next useful action in the existing durable
record. Save progress when it becomes useful, not only at the final response.
Do not create another memory service or duplicate the whole research corpus.

Report what is authored, read, checked and experimentally observed separately.
Where research evaluates a method, distinguish locating a rule, loading it,
following it and measuring its effect. Missing traces leave causes uncertain.
Source limitations and remaining user corrections can be more informative than
a single aggregate score. A successful pilot does not establish universal
effectiveness, portability or quota savings.
