# Source attribution for the durability study

The Game Design diagnostic reproduces selected source files from
[Muratovnik/gamedesign-skills](https://github.com/Muratovnik/gamedesign-skills/tree/a0db5af71146586cf861881670c991ad94d87e2b),
revision `a0db5af71146586cf861881670c991ad94d87e2b`, as evaluation inputs.
The input slice retains its original `LICENSE` and `NOTICE.md`; rewritten
README proposals are evaluation outputs, not upstream publication.

The other task fixtures are synthetic evaluation material. Research publications
and comparison projects are linked as sources; their articles, games and artwork
are not included or relicensed by this study.
