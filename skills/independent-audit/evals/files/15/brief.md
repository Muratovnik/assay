# Maintainer onboarding acceptance

Review the complete frozen documentation candidate in `repo/` for current
maintainer onboarding. A new maintainer must use the supported service checks
without disabling audit logging. Historical incident procedures may be retained
for explanation, but must not become required current operating steps.

The supplied files are the entire candidate; README is its entry point. Assess
documentation behavior by reading it. No running service, Git history, other
checkout, execution, edits, or publication are in scope.
