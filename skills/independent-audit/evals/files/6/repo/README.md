# Reference bundle

Start with the [design record](docs/design-record.md) for compatibility rationale.
The remaining document is retained historical material, not current user guidance.

Before selecting the bundle, its preparer can run `python -B tools/check.py`
in the source tree to check manifest paths and document headers. The validator
and manifest are source-only tooling, not recipient prerequisites.
This page is the reader entry point for the selected documents.
